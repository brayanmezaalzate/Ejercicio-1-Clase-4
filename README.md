# meza-brayan

Repositorio personal destinado al almacenamiento y organización de proyectos, ejercicios y actividades desarrolladas durante mi proceso de formación en Ingeniería de Sistemas.

## Descripción

Este repositorio contiene diferentes implementaciones y prácticas enfocadas en el aprendizaje de conceptos fundamentales de programación, estructuras de datos, algoritmos y desarrollo de software.

Cada proyecto o ejercicio se encuentra organizado en carpetas independientes, permitiendo una mejor distribución del código y facilitando su revisión.

## Estructura del repositorio

```
meza-brayan/
│
├── ejercicio-01/
│   └── Código fuente del ejercicio
│
├── ejercicio-02/
│   └── Código fuente del ejercicio
│
└── README.md
```

## Tecnologías utilizadas

Las tecnologías empleadas en este repositorio pueden incluir:

- Lenguajes de programación utilizados durante el desarrollo de los ejercicios.
- Herramientas de control de versiones.
- Entornos de desarrollo y herramientas complementarias.

## Instalación y ejecución

Para utilizar los proyectos almacenados en este repositorio:

1. Clonar el repositorio:

```bash
git clone https://github.com/brayanmezaalzate/meza-brayan.git
```

2. Ingresar al directorio del proyecto:

```bash
cd meza-brayan
```

3. Acceder a la carpeta del ejercicio o proyecto que se desea ejecutar.

4. Seguir las instrucciones específicas indicadas dentro de cada carpeta.

## Organización de proyectos

Cada carpeta contiene:

- Código fuente.
- Archivos necesarios para la ejecución.
- Documentación específica cuando sea requerida.
- Recursos adicionales utilizados durante el desarrollo.
